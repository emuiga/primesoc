# Fonts

Three proprietary CrowdStrike / Haas typefaces power the typography system.

---

## 1. CrowdStrikeSharpSans-Bold (700) — main headings

Place files here to activate:

- `CrowdStrikeSharpSans-Bold.woff` ✓ present
- `CrowdStrikeSharpSans-Bold.ttf`  ✓ present

Falls back to **Barlow 700** (Google Fonts) until files are present.

---

## 2. NeueHaasDisplayPro-Light (300–450) — subtitles & body copy

Place files here to activate:

- `NeueHaasDisplayPro-Light.otf` ✓ present (sourced from HelveticaNeueLight)

Falls back to **Helvetica → Arial → sans-serif**.

---

## 3. HaasGrotDisp-65Medium (500) — card titles & secondary headings

Place files here to activate:

- `HaasGrotDisp-65Medium.woff2` ✓ present
- `HaasGrotDisp-65Medium.woff`  ✓ present
- `HaasGrotDisp-65Medium.ttf`   ✓ present

Falls back to **Helvetica → Arial → sans-serif**.

---

> Do NOT commit font files to the public repo — these are proprietary.
> Add `public/fonts/*.woff*`, `public/fonts/*.otf`, `public/fonts/*.ttf` to `.gitignore`.
